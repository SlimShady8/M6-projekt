# GameFund – M6-projekt

GameFund er en crowdfunding-hjemmeside for to spil, **Snake** og **Tetris**, som
vi har udviklet fra bunden. Dette er vores M6-projekt på ITL, 2. semester.

**Live:** åbn `forside.html` i en browser
**Udviklet af:** Mads Erichsen & Sathurrsan Jalareenleney

---

## Om projektet

Siden er bygget i ren HTML, CSS og JavaScript uden frameworks. Den indeholder en
kampagneside, to spillbare spil, et lokalt leaderboard og formularer til
donationer og kontakt.

## Kom i gang

```bash
git clone https://github.com/SlimShady8/M6-projekt.git
```

Åbn derefter `forside.html` i en browser.

## Dokumentation

Den tekniske dokumentation findes i en selvstændig fil:

- [TEKNISK_DOKUMENTATION.md](TEKNISK_DOKUMENTATION.md) – teknologier,
  filstruktur, arkitektur og forklaring af koden.

## Funktioner

- Snake-spil med highscore (piletaster, WASD og mobil-D-pad)
- Tetris-spil
- Lokalt leaderboard
- Donations- og belønningssystem
- Responsivt design
